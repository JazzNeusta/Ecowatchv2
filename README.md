# Ecowatch V2

Structure simplifiée du projet Ecowatch.

## Frontend

Application React.

- `src/ui` : éléments d'interface simples et réutilisables.
- `src/components` : composants fonctionnels ou métier.
- `src/pages` : pages principales de l'application.
- `src/services` : appels API.
- `src/styles` : styles globaux.

## Backend

API Node.js / Express.

- `config` : configuration de l'environnement, CORS et base de données.
- `routes` : routes API.
- `controllers` : logique appelée par les routes.
- `middlewares` : middlewares Express.
- `utils` : fonctions utilitaires.
- `sql` : scripts SQL utiles.
